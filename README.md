# D-Mart – Online Grocery Shopping Website (Practice Project)

An online grocery store front-end built with **HTML5**, **CSS3** and **JavaScript**.

> **Disclaimer:** This is a practice project created for learning purposes only. It is a front-end clone and is **not** the official D-Mart / DMart Ready website and is not affiliated with Avenue Supermarts or Avenue E-Commerce Limited.

## 📌 About

This project recreates the look and feel of an online grocery shopping homepage. Products are loaded from a JavaScript array, can be filtered by category, and can be added to a working shopping cart.

## ✨ Features

- Fixed header with logo, delivery location, delivery slot, search bar, sign-in, notifications and cart
- Search bar with rotating placeholder text
- Delivery location popup
- Sign In / Register popup
- Notification side panel
- Auto-sliding banner
- Popular category slider with left / right arrows
- Product listing generated with JavaScript
- Category filter buttons
- Add to cart with quantity increase, decrease and remove
- Live cart item count and total amount
- Estimated delivery date calculated automatically (5 days from today)
- Popular searches and all categories sections
- Footer with app download buttons, payment icons and policy links

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, fixed header, modals, hover effects)
- JavaScript (DOM manipulation, arrays, array methods, template literals, event listeners)
- [Font Awesome 6.4](https://fontawesome.com/) for icons

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

An internet connection is needed to load the Font Awesome icons.

## 🧠 How the Cart Works

- Products are stored in the `products` array in `script.js`.
- Clicking **Add To Cart** adds the product to the `cart` array with a quantity of 1.
- The **+** and **−** buttons change the quantity, and the **×** button removes the product.
- The header updates the item count and total amount every time the cart changes.
